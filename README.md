Customer Shopping Behavior Analysis







End-to-end customer analytics project using Python, PostgreSQL and Power BI to clean customer shopping data, answer business questions with SQL, and build an interactive dashboard for understanding customer behavior, purchasing patterns, subscription activity, discounts, shipping preferences and revenue performance.

📌 Project Overview

This project analyzes a customer shopping behavior dataset containing 3,900 customer purchase records and 18 original attributes.

The workflow covers the complete analytics lifecycle:

Raw Data → Python Data Cleaning & Transformation → PostgreSQL → SQL Business Analysis → Power BI Dashboard → Business Insights

The project was designed around practical questions that a retail/e-commerce analytics team could ask about customers, products, revenue, discounts, subscriptions, shipping and purchasing behavior.

🎯 Business Problem

Retail businesses collect large amounts of customer transaction data, but raw transaction records alone do not clearly explain:

How much revenue is generated by different customer segments?

Do subscribed customers spend differently from non-subscribers?

Which products receive the highest customer ratings?

Which products rely most heavily on discounts?

Which products are purchased most frequently within each category?

How does purchasing behavior vary across age groups?

Are repeat buyers more likely to subscribe?

How do shipping methods relate to average purchase value?

The goal of this project is to transform the raw customer data into clear, decision-oriented analysis that can support marketing, customer retention, product and sales decisions.

🎯 Project Objectives

Clean and prepare the raw customer shopping dataset.

Load the transformed dataset into a relational database.

3. Handle missing review ratings

The dataset contained 37 missing values in Review Rating.

Instead of dropping those records, the missing ratings were filled using the median rating of the corresponding product category.

df['Review Rating'] = (
    df.groupby('Category')['Review Rating']
      .transform(lambda x: x.fillna(x.median()))
)

4. Standardize column names

Column names were converted to lowercase and spaces were replaced with underscores.

Purchase Amount (USD) was renamed to:

purchase_amount

This makes the dataset easier to work with in Python and SQL.

5. Create Age Group

Customers were divided into four age groups using quartiles:

Young Adult

Adult

Senior

labels = ['Young Adult', 'Adult', 'Middle-aged', 'Senior']

df['age_group'] = pd.qcut(
    df['age'],
    q=4,
    labels=labels
)

🧠 SQL Business Analysis

The project contains 10 business questions designed to demonstrate practical SQL skills.

Q1. Revenue by Gender

Business question:
What is the total revenue generated by male vs. female customers?

SQL concepts:

GROUP BY

SUM()

SELECT gender,
       SUM(purchase_amount) AS revenue
FROM customer
GROUP BY gender;

Q2. Discounted Purchases Above Average Spend

Business question:
Which customers used a discount but still spent more than or equal to the average purchase amount?

SQL concepts:

Filtering

Subquery

AVG()

SELECT customer_id,
       purchase_amount
FROM customer
WHERE discount_applied = 'Yes'
  AND purchase_amount >= (
      SELECT AVG(purchase_amount)
      FROM customer
  );
