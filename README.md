## 📌 Project Overview

This is an end-to-end **Customer Shopping Behavior Analysis** project built using **Python, PostgreSQL, SQL, and Power BI**.

The project analyzes **3,900 customer shopping records** to understand purchasing patterns, customer segments, product performance, subscription behavior, discount usage, shipping preferences, and revenue contribution across different customer groups.

The complete workflow follows:

**Raw Data → Python Data Cleaning → Feature Engineering → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights**

---

## 🎯 Business Problem

Retail businesses collect large amounts of customer transaction data, but raw data does not immediately provide useful business insights.

This project focuses on answering questions such as:

- How much revenue is generated by different customer groups?
- Do subscribed customers spend differently from non-subscribers?
- Which products have the highest customer ratings?
- Which products have the highest discount usage?
- Which products are purchased most frequently within each category?
- How does revenue vary across age groups?
- Are repeat customers more likely to subscribe?
- How does average purchase value differ between shipping methods?

The objective is to transform raw customer data into meaningful analysis that can support **customer, product, sales, marketing, and retention decisions**.

## 3. Handle Missing Values

There were **37 missing values** in the `Review Rating` column.

Instead of removing these records, missing ratings were replaced with the **median rating of the corresponding product category**.

```python
df['Review Rating'] = (
    df.groupby('Category')['Review Rating']
      .transform(lambda x: x.fillna(x.median()))
)
```

This preserved the customer records while providing a category-based estimate for the missing ratings.

---

# 🧠 SQL Business Analysis

The project contains **10 business-focused SQL questions**.

---

## Q1. Revenue by Gender

### Business Question

What is the total revenue generated by male vs. female customers?

### SQL Concepts

* `GROUP BY`
* `SUM()`

```sql
SELECT gender,
       SUM(purchase_amount) AS revenue
FROM customer
GROUP BY gender;
```

---

## Q2. Discounted Customers Spending Above Average

### Business Question

Which customers used a discount but still spent more than or equal to the average purchase amount?

### SQL Concepts

* `WHERE`
* Subquery
* `AVG()`

```sql
SELECT customer_id,
       purchase_amount
FROM customer
WHERE discount_applied = 'Yes'
  AND purchase_amount >= (
      SELECT AVG(purchase_amount)
      FROM customer
  );
```

---

## Q3. Top 5 Products by Average Review Rating

### Business Question

Which five products have the highest average customer review rating?

### SQL Concepts

* `GROUP BY`
* `AVG()`
* `ROUND()`
* `ORDER BY`
* `LIMIT`

```sql
SELECT item_purchased,
       ROUND(AVG(review_rating::numeric), 2) AS "Average Product Rating"
FROM customer
GROUP BY item_purchased
ORDER BY AVG(review_rating) DESC
LIMIT 5;
```

---

## Q4. Standard vs. Express Shipping

### Business Question

How does the average purchase amount compare between Standard and Express shipping?

### SQL Concepts

* `WHERE`
* `IN`
* `GROUP BY`
* `AVG()`

```sql
SELECT shipping_type,
       ROUND(AVG(purchase_amount), 2)
FROM customer
WHERE shipping_type IN ('Standard', 'Express')
GROUP BY shipping_type;
```

---

## Q5. Subscribers vs. Non-Subscribers

### Business Question

Do subscribed customers spend more?

The analysis compares:

* Total customers
* Average spending
* Total revenue

### SQL Concepts

* `COUNT()`
* `AVG()`
* `SUM()`
* `GROUP BY`

```sql
SELECT subscription_status,
       COUNT(customer_id) AS total_customers,
       ROUND(AVG(purchase_amount), 2) AS avg_spend,
       ROUND(SUM(purchase_amount), 2) AS total_revenue
FROM customer
GROUP BY subscription_status;
```

---

## Q6. Products with the Highest Discount Rate

### Business Question

Which five products have the highest percentage of purchases where a discount was applied?

### SQL Concepts

* `CASE WHEN`
* Conditional aggregation
* Percentage calculation
* `COUNT()`
* `SUM()`

```sql
SELECT item_purchased,
       ROUND(
           100.0 * SUM(
               CASE
                   WHEN discount_applied = 'Yes' THEN 1
                   ELSE 0
               END
           ) / COUNT(*),
           2
       ) AS discount_rate
FROM customer
GROUP BY item_purchased
ORDER BY discount_rate DESC
LIMIT 5;
```

---

## Q7. Customer Segmentation

Customers were segmented based on their number of previous purchases.

| Previous Purchases | Customer Segment |
| -----------------: | ---------------- |
|                  1 | New              |
|               2–10 | Returning        |
|                >10 | Loyal            |

### SQL Concepts

* CTE
* `CASE`
* Customer segmentation
* `GROUP BY`

```sql
WITH customer_type AS (
    SELECT customer_id,
           previous_purchases,
           CASE
               WHEN previous_purchases = 1 THEN 'New'
               WHEN previous_purchases BETWEEN 2 AND 10 THEN 'Returning'
               ELSE 'Loyal'
           END AS customer_segment
    FROM customer
)

SELECT customer_segment,
       COUNT(*) AS "Number of Customers"
FROM customer_type
GROUP BY customer_segment;
```

---

## Q8. Top 3 Products Within Each Category

### Business Question

What are the three most purchased products within each category?

This query uses a window function:

```sql
ROW_NUMBER() OVER (
    PARTITION BY category
    ORDER BY COUNT(customer_id) DESC
)
```

### SQL Concepts

* CTE
* `ROW_NUMBER()`
* `PARTITION BY`
* Window functions
* Aggregation
* Top-N analysis

```sql
WITH item_counts AS (
    SELECT category,
           item_purchased,
           COUNT(customer_id) AS total_orders,
           ROW_NUMBER() OVER (
               PARTITION BY category
               ORDER BY COUNT(customer_id) DESC
           ) AS item_rank
    FROM customer
    GROUP BY category, item_purchased
)

SELECT item_rank,
       category,
       item_purchased,
       total_orders
FROM item_counts
WHERE item_rank <= 3;
```

## Q9. Repeat Buyers & Subscription

### Business Question

Are customers with more than five previous purchases also likely to subscribe?

```sql
SELECT subscription_status,
       COUNT(customer_id) AS repeat_buyers
FROM customer
WHERE previous_purchases > 5
GROUP BY subscription_status;
```

This helps examine the relationship between repeat purchasing behavior and subscription status.

## Q10. Revenue by Age Group

### Business Question

What is the revenue contribution of each age group?

```sql
SELECT age_group,
       SUM(purchase_amount) AS total_revenue
FROM customer
GROUP BY age_group
ORDER BY total_revenue DESC;
```
